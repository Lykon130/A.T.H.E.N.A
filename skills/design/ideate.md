---
name: ideate
department: design
stage: human-led
description: Use when the user wants creative/visual direction — concepts for a carousel, thumbnail ideas, a mood board direction, or general "give me some creative options".
---

1. Read style preferences from `vault/wiki/departments/design.md` and any relevant script/hook from Marketing if this is for a content piece.
2. Generate 3-5 distinct creative directions — describe each concretely enough to brief a designer (or an image-gen tool, if one's connected) rather than vague mood words.
3. Write to `vault/outputs/design-ideas-{topic}-{date}.md`.
4. This produces direction/briefs, not final assets — actual image/video generation is a separate step using whatever tool is connected.
