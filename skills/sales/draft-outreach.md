name: draft-outreach
department: sales
stage: human-led
description: Use when the user wants a draft outreach message, cold email, or follow-up to a lead/client.
---

1. Pull context on the recipient from `vault/wiki/departments/sales.md` or prior notes if they exist.
2. Draft the message — short, specific, one clear ask.
3. Write the draft to `vault/outputs/outreach-{recipient}-{date}.md`.
4. **Never send it.** This skill only drafts. Sending any message on the user's behalf requires their explicit go-ahead in the moment, every time — draft here, send yourself (or confirm explicitly if wired to a send-capable connector later).
