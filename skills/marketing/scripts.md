---
name: scripts
department: marketing
stage: human-led
description: Use when the user wants a script for a reel/video, or copy for a carousel post, built from a chosen hook.
---

1. Take the chosen hook (from `hooks` or given directly).
2. Structure per format:
   - Reel/video: Hook → Problem → Solution → Proof → CTA.
   - Carousel: Hook/title → key points (one per slide) → summary/CTA.
3. Write to `vault/outputs/script-{topic}-{date}.md`.
4. This produces the script/copy only — actual recording, design, and posting are separate steps the user does (or a `design-brief`/publishing skill would handle, not yet built).
