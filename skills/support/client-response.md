---
name: client-response
department: support
stage: human-led
description: Use when the user wants a draft reply to a client question, complaint, or support request.
---

1. Read the incoming message/question.
2. Check `vault/wiki/departments/support.md` for known answers/FAQ patterns already logged.
3. Draft a clear, direct response — no filler.
4. Write draft to `vault/outputs/response-{client}-{date}.md`. Draft only — same rule as `draft-outreach`, sending requires the user's explicit action.
5. If this is a new/recurring question, add it to the FAQ pattern list in the department note so next time is faster.
