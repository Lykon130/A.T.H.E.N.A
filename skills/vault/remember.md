description: Use whenever the user shares a preference, personal fact, recurring person/project, important date, or explicitly says "remember this". Cross-cutting — every other skill should read profile.md for context.

1. Identify the durable fact (not a one-off detail — something worth knowing next time, not just today).
2. Check `vault/wiki/profile.md` for an existing entry on the same topic — update in place rather than duplicating.
3. File it under the right section: Preferences, People & Relationships, Projects, Important Dates, or Communication Style.
4. Update the "Last updated" line.
5. Every other skill (especially `book-appointment`, `draft-outreach`, `client-response`, `plan`) should check this file before producing output — a booking should already know dietary preferences, an outreach draft should already know tone preferences, etc.

This is the same idea as an AI assistant's own memory file, applied to you — a living profile, not a transcript log. Don't dump every conversation detail here, only what's actually worth carrying forward.
